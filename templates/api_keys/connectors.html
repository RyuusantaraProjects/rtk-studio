OpenAPI Spec

Langkah-langkah di chatgpt.com:

  1. Buka GPT Editor → Tab Configure → Klik Create new action.
  2. Pada bagian Authentication, pilih API Key, Auth Type: Bearer, dan masukkan token API Key Anda.
  3. Pada bagian Schema, klik Import from URL lalu tempelkan URL skema di bawah ini:
{{ openapi_url }}

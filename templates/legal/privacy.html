Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: {{ last_updated }}

Di RTK Studio ("kami", "aplikasi"), kami sangat menghargai dan memprioritaskan privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana informasi Anda dikumpulkan, digunakan, dilindungi, dan dikelola saat Anda menggunakan layanan kami di https://studio.rtk.my.id.

Prinsip Utama: Kami TIDAK PERNAH menjual, menyewakan, atau memperjualbelikan data pribadi atau data akun media sosial Anda kepada pihak ketiga atau pengiklan mana pun. Semua data yang kami proses digunakan murni untuk memfasilitasi fungsionalitas yang Anda aktifkan secara eksplisit.

1. Informasi yang Kami Kumpulkan

Kami mengumpulkan jenis data berikut sesuai dengan kebutuhan operasional layanan:

A. Informasi Akun Pengguna

  • Data Profil: Nama lengkap, alamat email, dan foto profil yang Anda sediakan saat pendaftaran atau login melalui Google Sign-In.
  • Data Keamanan: Kata sandi (disimpan secara satu arah menggunakan algoritma hashing cryptographic yang kuat), stempel waktu persetujuan syarat & ketentuan.

B. Informasi Akun Media Sosial yang Dihubungkan (via OAuth)

Saat Anda memilih untuk menghubungkan akun media sosial (Meta, Facebook, Instagram, Threads, TikTok, YouTube, LinkedIn, dll.), kami menerima data otorisasi resmi melalui protokol OAuth:

  • Identitas Akun: Akun ID unik pihak ketiga (misal: Facebook Page ID, Instagram Business Account ID), nama akun, username/handle (@username), dan tautan foto avatar.
  • Kredensial Otorisasi: Access Token dan Refresh Token OAuth. Kredensial ini selalu disimpan dalam keadaan terenkripsi kuat (AES-256) di basis data kami dan tidak pernah dibuka untuk publik.
  • Statistik Publik Terbatas: Jumlah pengikut (follower count) untuk keperluan laporan ringkasan profil Anda.

C. Konten yang Dijadwalkan dan Media

  • Teks postingan, tag, keterangan (caption), serta file media (gambar, video) yang Anda unggah ke Pustaka Media kami untuk dipublikasikan.
  • Jadwal penerbitan dan status penerbitan postingan.

D. Data Interaksi Kotak Masuk (Inbox)

  • Komentar publik pada postingan yang Anda terbitkan dan pesan langsung (Direct Messages) yang dikirimkan oleh pengikut Anda ke akun bisnis yang terhubung, guna memungkinkan Anda membaca dan membalas pesan tersebut langsung dari antarmuka RTK Studio.

2. Penggunaan Izin Khusus Meta / Instagram

Untuk integrasi dengan Meta API (Facebook Login, Instagram Graph API, dan Instagram API with Instagram Login), kami hanya meminta izin spesifik berikut dan menggunakannya untuk tujuan yang jelas:

  • instagram_business_basic: Untuk mengidentifikasi akun bisnis Instagram Anda, menampilkan foto profil, dan memverifikasi status koneksi.
  • instagram_business_content_publish: Digunakan hanya ketika Anda secara sengaja menjadwalkan atau mempublikasikan foto, video, Reels, atau carousel ke akun Instagram Anda.
  • instagram_business_manage_comments: Digunakan untuk menampilkan komentar terbaru pada postingan Instagram Anda ke dalam Inbox RTK Studio dan mengirim balasan komentar dari Anda.
  • instagram_business_manage_messages: Digunakan untuk menampilkan pesan langsung yang masuk dan memfasilitasi pengiriman balasan chat oleh tim Anda.
  • instagram_business_manage_insights: Untuk menyajikan analitik performa postingan dan pertumbuhan jangkauan konten Anda dalam dasbor analitik.
  • pages_manage_posts, pages_read_engagement, pages_messaging: Fungsi yang setara untuk Facebook Pages resmi Anda.

3. Bagaimana Kami Melindungi dan Menyimpan Data Anda

Keamanan data Anda adalah prioritas tertinggi kami:

  • Enkripsi Tingkat Tinggi: Seluruh token OAuth dan kunci rahasia disimpan di database dengan enkripsi tingkat lanjut (enkripsi simetris AES).
  • Koneksi Terenkripsi: Seluruh komunikasi antara peramban Anda, server RTK Studio, dan API platform pihak ketiga dienkripsi menggunakan HTTPS/TLS modern.
  • Pemisahan Ruang Kerja (Workspace Isolation): Setiap organisasi dan workspace memiliki isolasi data yang ketat. Anggota tim hanya dapat melihat akun dan konten yang diizinkan oleh peran (role) mereka.

4. Pembagian Data dengan Pihak Ketiga

Kami tidak membagikan data pribadi Anda kepada pihak luar, kecuali dalam skenario operasional berikut:

  • Penyedia Platform Media Sosial: Saat mempublikasikan konten atau mengambil pesan/analitik, data dikirim langsung ke server resmi penyedia platform (Meta, Google, TikTok, LinkedIn) sesuai permintaan Anda.
  • Kepatuhan Hukum: Jika diwajibkan secara tegas oleh hukum, panggilan pengadilan, atau perintah pihak berwenang yang sah di Republik Indonesia.

5. Retensi dan Penyimpanan Data

Data Anda disimpan selama akun Anda aktif di RTK Studio:

  • Jika Anda memutuskan akun media sosial tertentu, seluruh token akses untuk akun tersebut akan seketika dihapus secara permanen dari basis data kami.
  • Jika Anda menghapus akun pengguna atau meminta penghapusan data, seluruh data pribadi, riwayat jadwal, dan token akan dimusnahkan.

6. Hak Pengguna dan Penghapusan Data (User Data Deletion)

Anda memiliki hak penuh untuk mengontrol data Anda:

  • Hak Akses & Pembaruan: Anda dapat memeriksa dan memperbarui informasi akun Anda kapan saja melalui dasbor pengaturan.
  • Hak Pencabutan Akses: Anda dapat memutuskan koneksi akun media sosial kapan saja di menu Settings > Social Accounts. Anda juga dapat mencabut izin aplikasi kami langsung dari menu pengaturan Facebook atau Instagram Anda.
  • Hak Penghapusan Data: Kami menyediakan panduan langkah demi langkah dan saluran resmi untuk menghapus seluruh data Anda dari sistem kami. Silakan lihat Panduan Penghapusan Data Pengguna kami.

7. Perubahan Kebijakan Privasi

Kami dapat meninjau dan memperbarui Kebijakan Privasi ini secara berkala untuk mencerminkan perubahan fitur atau kepatuhan regulasi. Tanggal "Terakhir diperbarui" di bagian atas halaman ini akan selalu mencerminkan revisi terbaru.

8. Kontak dan Petugas Perlindungan Data

Jika Anda memiliki pertanyaan, keluhan, atau permohonan terkait privasi dan perlindungan data pribadi Anda, silakan hubungi kami di:

  • Email Privasi & Dukungan: support@rtk.my.id
  • Alamat Layanan: RTK Studio, Lampung, Indonesia
